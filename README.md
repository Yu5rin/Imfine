# I'm fine

モニターのスリープと Microsoft Teams の「退席中」表示を防ぐ Windows 用常駐ツールです。

## 主な機能

- ワンクリックの ON/OFF トグルスイッチ（アニメーション付き）
- ON の間はモニタースリープを抑止し、30秒ごとにアクティブ状態を維持
  （F15キーの押下イベントとマウスの1px移動を、その時点でフォアグラウンドに
  ある任意のアプリへ送信する方式です。ゲームやリモートデスクトップ、
  F15キーにショートカットを割り当てているアプリでは意図しない副作用が
  起きる可能性があります。また、キー入力・マウス操作のシミュレーションを
  行うため、企業環境ではこの挙動自体が監視・検知の対象になり得る点にも
  注意してください）
- 停止時刻を指定して自動 OFF（動作中の変更も即反映）
- タスクトレイ常駐（停止中はグレー、動作中は緑のアイコン）
  - 左クリック: ON/OFF 切り替え（トースト通知で状態表示）
  - 左ダブルクリック: メイン画面を表示
  - 右クリック: メニュー（タスクトレイから出す / 更新を確認 / 終了）
- ライト / ダークテーマ切り替え
- 起動時に自動で ON にするオプション
- Windows 起動時の自動起動オプション
- ウィンドウ位置と設定の自動保存
- 起動時に直接タスクトレイへ格納するオプション
- 自動アップデート（設定で有効/無効を切り替え可能。有効時は起動するたびに
  新しいバージョンがないか確認し、あればダウンロード・SHA256検証・
  自己置き換え・再起動まで自動で行う。検証に失敗した場合は何もせず現在の
  バージョンのまま動作を続ける）
  - この SHA256 検証は、ダウンロードした exe と GitHub API が返す期待値
    (同じレスポンスに含まれる digest) を突き合わせるものです。つまり
    **通信中の破損や取りこぼしを検知するためのものであり**、GitHub の
    アカウントが乗っ取られてリリース自体が改ざんされた場合の検知には
    なりません（exe とハッシュを同時に差し替えられてしまうため）。
  - 更新確認先は `api.github.com` に固定されており、設定ファイルを
    直接編集しても他のホストへ変更することはできません
    （更新の仕組みが任意のサーバーへの自己置き換えに悪用されるのを
    防ぐための制限です）。

## 動作環境

- Windows 10 / 11（64ビット）
- タイトルバーの色をテーマに合わせる表示は Windows 11 22H2（ビルド 22621）以降のみ。
  それより前の環境では OS 標準のタイトルバーのまま動作します
- 自動アップデートを使う場合は `api.github.com` と GitHub のダウンロード用ホストへ
  接続できること

## インストールと更新

### インストール

Releases ページから最新の ImFine.exe をダウンロードして実行するだけです。
インストール不要のポータブル形式です。

https://github.com/Yu5rin/Imfine/releases

ImFine.exe は、自分で書き込みできるフォルダ（例: ドキュメントやデスクトップの下）に
置いてください。自動アップデートは ImFine.exe のあるフォルダで exe を入れ替えるため、
書き込みできない場所（`C:\Program Files` など）では更新が行われません。

### 更新

- **自動アップデート（既定で有効）**: 起動するたびに新しいバージョンがないか確認し、
  あればダウンロード・SHA256検証・入れ替え・再起動まで自動で行います。ON のまま
  更新された場合は、再起動後も ON に戻ります
- **手動で確認する**: 設定ウィンドウの「今すぐ更新を確認」、またはタスクトレイの
  右クリックメニューの「更新を確認」から、自動アップデートの設定に関係なく確認できます
- **自分で入れ替える**: 自動アップデートを無効にしている場合や、自動で更新できない
  場合は、Releases ページから最新の ImFine.exe をダウンロードし、今ある ImFine.exe と
  置き換えてください。設定は別の場所（下の「設定ファイル」）に保存されているため、
  そのまま引き継がれます

更新の記録は `%APPDATA%\ImFine\update.log` に残ります。更新がうまくいかない
場合は、このファイルを見ると原因が分かります。

## 使い方

1. ImFine.exe を起動する
2. 中央のトグルスイッチをクリックして ON にする
3. 最小化、またはウィンドウの × ボタンでタスクトレイに格納される（設定で変更可能。
   終了はタスクトレイの右クリックメニューの「終了」から）

### 設定

メイン画面右上の「設定」ボタンから設定ウィンドウを開きます。

- **テーマ** … ライト / ダークの切り替え
- **起動と常駐** … 最小化でタスクトレイ格納、起動時にタスクトレイへ格納、
  起動時に自動で ON、Windows 起動時に起動
- **更新** … 自動アップデートの有効/無効、「今すぐ更新を確認」ボタン

### 停止時刻

「有効」にチェックを入れて時刻を設定すると、その時刻に自動で OFF になります。
指定時刻が現在より前の場合は翌日のその時刻に停止します。

## 開発

Python 3.11 + tkinter 製。ビルドには PyInstaller を使用します。

```
pip install -r requirements.txt
python icon_gen.py
pyinstaller ImFine.spec
```

テストは `python -m unittest discover -s tests` で回します（標準ライブラリだけで動きます）。

GitHub Actions の Build and Release ワークフローを手動実行すると、
ui.py のバージョンを読み取って自動でタグ付け・リリースされます。

### リリース手順

1. リリース前に `CHANGELOG.md` へ `## v<バージョン>` の節を追記する（見出しはリリースタグ名と完全一致させること）
2. `ui.py` の `VERSION` をその版に上げる（画面に出るバージョンはここから取る。タグと一致しないとビルド前にワークフローが失敗する）
3. ワークフローを実行する（該当節が無いとビルド前にワークフローが失敗する）
4. ワークフローが `CHANGELOG.md` の該当節を自動的に抜き出し、GitHub リリースのリリースノートとして反映する

リリースの本文は「## 変更点」（`CHANGELOG.md` の該当節）と「## ダウンロード」
（ファイル・サイズ・SHA256 の表）の2節と、この README への案内1行だけで作られます。
インストールや更新の方法、機能の説明などは README に書き、リリースには書きません。
`CHANGELOG.md` の節の中では、見出しは `###` 以下を使ってください。

## 設定ファイル

%APPDATA%\ImFine\settings.json に保存されます。
旧バージョン（Mouser）の設定は初回起動時に自動で引き継がれます。
